# Deux projets SQL

## projet Donateur 
Une requête SQL réelle que j'ai écrite pour un cas d'usage d'analyse de
donateurs et de membres, accompagnée de la version améliorée que j'écrirais
aujourd'hui. J'ai conservé les deux volontairement : l'écart entre elles est un
instantané de l'évolution de ma pratique SQL.

## Projet Salle

Basé sur un jeu de données fictifs entourant la programmation de la place des arts. 
Création de requêtes pouvant être utile dans le quotidien d'un analyste de données afin de déterminer
1)la courbe des ventes, notamment
2)la segmentation de la clientèle
3)Le taux de remplissage.
4) Une vue d'ensemble de la saison
5) Le rapport quotidien d'évolution
6) Les 10 productions ayant généré le plus de recettes
